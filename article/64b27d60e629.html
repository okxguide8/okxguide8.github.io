阿里Qwen Code 1.0发布：Qoder与Qwen Code Harness融合开源

2026-11-11 13:11 ·PANews ·349 字

PANews 11月11日消息，据IT之家报道，阿里宣布推出Qwen Code 1.0版本，并将Qoder与Qwen Code融合开源。阿里将Qoder中打磨的Harness能力融入Qwen Code，随Qwen Code 1.0 Preview一起开放，为开发者提供可嵌入自身产品的Agent运行基础。

Qwen Code 1.0从进程内的内存事件总线起步，向分布式演进，将接入、调度与执行分层扩展，通过“手脑分离”让推理编排与工具执行独立管理。本次发布将Qoder与Qwen Code的Harness能力纳入同一套开源内核，Harness负责衔接模型、工具与执行过程，开发者可据此构建适合自身场景的Agent系统。Qwen Code 1.0 Preview以独立分支开放，现有稳定分支继续保留。
