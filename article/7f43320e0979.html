SignalPlus：已全额赔付23名受影响用户，总计81897美元

2026-11-08 11:14 ·PANews ·362 字

PANews 11月8日消息，SignalPlus 发文表示，自 11 月 4 日发现异常活动后，已在 72 小时内完成对全部 23 名受影响用户的全额赔付，总金额为 81897 美元。事件发生后，SignalPlus 立即通知合作交易所，提议并推动暂停所有相关 API 密钥，同时暂停受影响平台服务并启动全面安全审查。团队在调查的同时联系用户完成核验，顺利完成赔付。目前平台正加强安全措施，包括提升 API 访问要求、实施 IP 白名单验证，以及收紧员工设备与内部访问控制。服务将在系统审查与升级完成后逐步恢复。

此前消息，SignalPlus 发布安全事件公告称，11 月 4 日凌晨检测到异常活动并确认遭受网络攻击，此次攻击源于一个第三方 Telegram 账户被入侵，导致部分未设置 IP 白名单的用户账户受到影响。
